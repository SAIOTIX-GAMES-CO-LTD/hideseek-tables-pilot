# hideseek-tables-pilot

Пилотные каналы таблиц HideSeek. Их публикует стенд игровых данных на сервере студии (Redmine #300–#302). Игра эти каналы не использует: сюда смотрит только проверочная сборка с ключом запуска `-table-url`.

- `weapons/test.json`, `weapons/release.json` — каналы: в каждом файле полный набор.
- `weapons/versions/<канал>/NNNN.json` — все опубликованные версии канала; по ним откатываются.
- `text/test.json` — снимок таблицы текстов Test из `hideseek-tables` (version 10, 23.11.2026): по нему стенд проверяет ключи названий и описаний оружия.

Руками файлы не править: публикует только стенд.

## 파일럿 채널

HideSeek 테이블의 파일럿 채널입니다. 스튜디오 서버의 게임 데이터 스탠드(Redmine #300–#302)가 게시합니다. 게임은 이 채널을 사용하지 않으며, 확인용 빌드만 실행 키 `-table-url`로 이 주소를 봅니다.

- `weapons/test.json`, `weapons/release.json` — 채널. 각 파일에 전체 세트가 들어 있습니다.
- `weapons/versions/<채널>/NNNN.json` — 채널에 게시된 모든 버전. 롤백할 때 사용합니다.
- `text/test.json` — `hideseek-tables`의 Test 텍스트 테이블 스냅샷(version 10, 2026-11-23). 스탠드가 무기 이름·설명 키를 검사할 때 사용합니다.

파일을 직접 수정하지 마세요. 게시는 스탠드만 합니다.
